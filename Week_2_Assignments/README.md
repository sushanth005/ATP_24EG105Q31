### Shallow Copy
Copies only the reference of nested objects.

### Deep Copy
Creates a completely independent copy of objects.

# ▶️ How to Run

## Step 1:
Install Node.js

## Step 2:
Clone the repository

```bash
git clone <repository-url>
````

## Step 3:

Open terminal inside project folder

## Step 4:

Run JavaScript files

```bash
node filename.js
```

### Example

```bash
node Ass_Promise.js
```

---

# ⚙️ Run Backend Server

Move into backend folder:

```bash
cd Backend_demo
```

Install dependencies:

```bash
npm install
```

Run server:

```bash
node app.js
```

Server runs on:

```bash
http://localhost:3000
```
