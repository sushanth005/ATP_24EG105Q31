## Assignment Highlights

### Temperature Analyzer

Analyzes temperature data and calculates:

- Average temperature
- Highest temperature
- Lowest temperature

### Student Performance System

Processes student marks and evaluates performance.

Features include:

- Average calculation
- Grade analysis
- Performance evaluation

### Employee Payroll System

Calculates employee salary details such as:

- Salary processing
- Bonus calculations
- Payroll management

### Movie Streaming Simulation

Simulates movie platform operations including:

- Movie listing
- Search functionality
- Streaming logic

### Bank Transaction Analyzer

Processes and analyzes banking transactions such as:

- Deposits
- Withdrawals
- Transaction summaries

### Library Management Using Classes

Implements object-oriented programming concepts.

Features include:

- Adding books
- Managing library records
- Borrow and return operations

### OTP Generator and Validator

Generates and validates one-time passwords.

Concepts used:

- Random number generation
- Validation logic

### Promise Examples

Demonstrates asynchronous programming with Promises.

Topics covered:

- Promise creation
- `.then()`
- `.catch()`
- Async handling

### Deep Copy and Shallow Copy

#### Shallow Copy

Creates a copy where nested objects still reference the original object.

#### Deep Copy

Creates a completely independent copy of the object, including nested objects.

## How to Run

### Step 1

Install Node.js on your system.

### Step 2

Clone the repository.

```bash
git clone <repository-url>
````

### Step 3

Open the terminal inside the project folder.

### Step 4

Run any JavaScript file.

```bash
node filename.js
```

#### Example

```bash
node Ass_Promise.js
```

---

## Running the Backend Server

Navigate to the backend folder.

```bash
cd Backend_demo
```

Install dependencies.

```bash
npm install
```

Start the server.

```bash
node app.js
```

The server will run at:

```bash
http://localhost:3000
```
