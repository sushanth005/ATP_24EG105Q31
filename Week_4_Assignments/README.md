# 🚀 Capstone Project - Backend

This capstone project backend is built using **Node.js**, **Express.js**, **MongoDB**, and **Mongoose**.  
It implements a complete **role-based article publishing system** with authentication, authorization, JWT security, and CRUD operations.

The backend supports three roles:

- USER
- AUTHOR
- ADMIN

---

# 📂 Project Structure

```bash
Capstone_Project/Backend
│
├── APIs/
│   ├── AdminAPI.js
│   ├── AuthorAPI.js
│   ├── CommonAPI.js
│   └── UserAPI.js
│
├── middlewares/
│   └── verifyToken.js
│
├── models/
│   ├── ArticleModel.js
│   └── UserModel.js
│
├── admin.http
├── author.http
├── user.http
├── server.js
├── package.json
├── package-lock.json
├── README.md
└── .env
````

* User Registration & Login

* Article Publishing System

# 🔐 Authentication & Authorization

The project uses:

* JWT Tokens
* HTTP-only Cookies
* Role-Based Middleware

### Middleware Features

* Token verification
* Role validation
* Protected routes

### Example

```js
verifyToken("AUTHOR")
```

Used to restrict access only to authors. 

---

# 👤 User Model

The user schema contains:

| Field           | Type                  |
| --------------- | --------------------- |
| firstName       | String                |
| lastName        | String                |
| email           | String                |
| password        | String                |
| role            | USER / AUTHOR / ADMIN |
| profileImageUrl | String                |
| isUserActive    | Boolean               |

### Features

* Unique email validation
* Role validation
* User activation status
* Automatic timestamps



---

# 📰 Article Model

The article schema contains:

| Field           | Type     |
| --------------- | -------- |
| title           | String   |
| category        | String   |
| content         | String   |
| author          | ObjectId |
| comments        | Array    |
| isArticleActive | Boolean  |

### Features

* Comments support
* Soft delete
* Author reference
* Timestamp tracking



---

# 🌐 API Routes

# 🔐 Authentication Routes

| Method | Endpoint         | Description     |
| ------ | ---------------- | --------------- |
| POST   | `/auth/users`    | Register user   |
| POST   | `/auth/login`    | Login           |
| GET    | `/auth/logout`   | Logout          |
| PUT    | `/auth/password` | Change password |

---

# ✍️ Author Routes

| Method | Endpoint               | Description         |
| ------ | ---------------------- | ------------------- |
| POST   | `/author-api/article`  | Publish article     |
| GET    | `/author-api/articles` | Read own articles   |
| PUT    | `/author-api/articles` | Edit article        |
| PATCH  | `/author-api/articles` | Soft delete article |

---

# 👀 User Routes

| Method | Endpoint             | Description       |
| ------ | -------------------- | ----------------- |
| GET    | `/user-api/articles` | Read all articles |
| PUT    | `/user-api/articles` | Add comment       |

# ⚙️ Server Configuration

The server:

* Uses Express.js
* Connects MongoDB using Mongoose
* Uses cookie-parser middleware
* Loads environment variables using dotenv

### Server File

```js
app.use("/user-api", userApp);
app.use("/author-api", authorApp);
app.use("/admin-api", adminApp);
app.use("/auth", commonApp);
```
