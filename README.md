
---

## How to Run Backend Projects

```bash
cd backend
npm install
```

Create a `.env` file:

```env
PORT=5000
DB_URL=your_mongodb_connection_string
SECRET_KEY=your_secret_key
```

Start the server:

```bash
node server.js
```
