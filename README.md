# How to Run React Projects

---

# Step 1

Move into project folder

```bash
cd project-folder
```

---

# Step 2

Install dependencies

```bash
npm install
```

---

# Step 3

Run project

```bash
npm run dev
```

---

# How to Run Backend Projects

---

# Step 1

Move into backend folder

```bash
cd backend
```

---

# Step 2

Install dependencies

```bash
npm install
```

---

# Step 3

Create `.env` file

```env
PORT=5000
DB_URL=your_mongodb_url
SECRET_KEY=your_secret_key
```

---

# Step 4

Run backend server

```bash
node server.js
```
